# LukRecovery

Recupere arquivos de HDs, SSDs e pendrives formatados com varredura profunda.

O LukRecovery reconhece todos os discos conectados ao computador, inclusive HDs em case USB, faz uma varredura completa e mostra tudo o que encontrou. Você escolhe se quer recuperar tudo, pastas inteiras ou só alguns arquivos.

## Download

**[Baixar a versão mais recente](https://github.com/LUKbrDEV/LukRecovery/releases/latest)**

Na página da versão, clique no arquivo `.exe` em **Assets**.

## Recursos

- Varredura profunda em discos formatados
- Reconhece discos internos e externos (USB)
- Lista todos os arquivos encontrados
- Recupere tudo, pastas ou arquivos selecionados
- Modo claro e modo escuro

## Requisitos

- Windows 10 ou Windows 11

## Como usar

1. Baixe e abra o `.exe`.
2. Escolha o disco de onde quer recuperar os arquivos.
3. Inicie a varredura e aguarde. Em discos grandes ela pode demorar.
4. Marque o que quer recuperar e escolha a pasta de destino.

## Dicas importantes

- **Salve os arquivos recuperados em outro disco**, nunca no mesmo de onde está recuperando. Gravar no mesmo disco pode sobrescrever arquivos que ainda poderiam ser recuperados.
- **Evite usar o disco** depois que perceber a perda dos arquivos. Quanto menos ele for usado, maiores as chances de recuperar tudo.
- Se o Windows mostrar o aviso **"O Windows protegeu o computador"**, clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece porque o programa ainda não tem assinatura digital paga.
